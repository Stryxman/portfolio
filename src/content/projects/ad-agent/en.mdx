From a **brief** (goal, art direction, hook, product, images), the agent produces several **static ad variants**, built on a library of formats drawn from real ads observed in the Meta Ad Library.

![Six variants generated by the agent for three fictional products](https://raw.githubusercontent.com/Stryxman/ad-agent/main/docs/screenshots/demo.png)

## How it works

1. Reads the brief, then analyses the images, removing the background only when it isn't already transparent.
2. Picks creative angles, with Claude or with a deterministic offline writer.
3. Selects formats by ratio, goal, niche and forbidden claims.
4. Writes the copy, checked line by line by code (length, forbidden claims, invented figures); prices, reviews and facts never go through the model.
5. Renders HTML then PNG with Jinja2 and Playwright, and exports a summary to review.

## What sets it apart

- A **real knowledge base**: eight formats documented from ads that have been running for weeks, never copying their visuals.
- An **AI writer kept under control**, re-checked by code before every use.
- A **deliberately chosen background-removal model** (commercially reusable licence), after narrowly avoiding a default model under a non-commercial licence.
- **101 tests**, plus real-world runs at every step.
